# Browser keyboard shortcuts

| Action | Mac shortcut |
| --- | --- |
| New Tab | ⌘T |
| New Private Tab in the current window | ⌘⇧N |
| New Private Window | ⌥⇧⌘N |
| Reopen Closed Tab | ⌘⇧T |
| Next / previous tab in sidebar order, wrapping | Ctrl+Tab / Ctrl+Shift+Tab |
| Next / previous tab (existing alternatives) | ⌘⇧] / ⌘⇧[ |
| Reload | ⌘R |
| Reload from origin, bypassing cache | ⌘⇧R or ⌥⌘R |
| Open Location | ⌘L |
| AutoFill Password… (focused login field) | ⌥⇧⌘P |
| Select profile 1–9 in Profiles menu order | ⌃1…9 |
| Previous / next profile, wrapping | ⌥⌘← / ⌥⌘→ |

Each **New Private Window** opens a separate window with its own sidebar and private
tabs. Use ⌘T there to open another private tab. Closing the window discards its
tabs and their browsing data. External private links keep their own window.

Ctrl+Tab works in web content and the address field. Other windows, Settings,
and sheets retain their own keyboard handling. Oriv leaves ⇧⌘\ unassigned.
Reader / Read Page Text remains available in the menus without a shortcut.
No Reader menu owns ⌘⇧R.

In either address editor, Up/Down selects a suggestion, Return opens it, and
Escape dismisses editing. Tab or Right Arrow accepts the selected inline host
suffix; Return also submits the completed host. Backspace and forward Delete
remove text without immediately reapplying completion. Marked IME text is never
replaced with a completion. iPhone supports these address-editor commands with a
hardware keyboard; this change adds no general iOS tab-switch commands.

| Mac sidebar action | Shortcut / key |
| --- | --- |
| Search tabs (title-bearing panel from the rail) | ⇧⌘A |
| Expand sidebar / collapse to favicon rail | ⌥⌘S |
| Dismiss rail search and restore prior focus; clear expanded search | Escape |
| Highlight pinned tiles and tab rows | Arrows, Home, End, Page Up, Page Down |
| Activate a focused tab | Return or Space |
| Enter the selected tab from the sidebar toggle | Down Arrow |
| Close the selected tab, including a pin | ⌘W |
| Mute or unmute the selected tab | ⌃⌘M |
| Select tabs in pinned-first visual order | ⌘1…8; ⌘9 selects the last tab |

Tab search matches titles and hosts in the active profile. It begins in the
selected tab’s privacy scope. Choose **Tabs** or **Private** in a mixed session
to change scope. Escape clears the expanded search or closes the rail panel
and restores prior focus. ⌘F finds text on the page.
Hover reveal is off by default in Settings → Appearance → Sidebar. Narrow
windows use the rail and can explicitly expand it over the page. Use the tab
context menu for Pin, Unpin, Move Up and Move Down. Tab and Shift-Tab reach
the profile picker, search, tab list, New Tab and footer. VoiceOver offers
row actions for close and mute.

Profile shortcuts apply in the regular browser window. macOS Mission Control
shortcuts assigned to Control plus a digit take precedence.
