# Browser keyboard shortcuts

| Action | Mac shortcut |
| --- | --- |
| Next / previous tab in sidebar order, wrapping | Ctrl+Tab / Ctrl+Shift+Tab |
| Next / previous tab (existing alternatives) | ⌘⇧] / ⌘⇧[ |
| Reload | ⌘R |
| Reload from origin, bypassing cache | ⌘⇧R or ⌥⌘R |
| Open Location | ⌘L |

Ctrl+Tab works in web content and the address field. In Tab Overview it moves
the selected item and keeps the sheet open. The router is window scoped; other
windows, Settings, and unrelated sheets retain their own keyboard handling.
Reader / Read Page Text remains available in the menus without a shortcut.
No Reader menu owns ⌘⇧R.

In either address editor, Up/Down selects a suggestion, Return opens it, and
Escape dismisses editing. Tab or Right Arrow accepts the selected inline host
suffix; Return also submits the completed host. Backspace and forward Delete
remove text without immediately reapplying completion. Marked IME text is never
replaced with a completion. iPhone supports these address-editor commands with a
hardware keyboard; this change adds no general iOS tab-switch commands.

| Mac sidebar action | Shortcut / key |
| --- | --- |
| Search tabs in the active profile (expands the rail) | ⇧⌘A |
| Expand sidebar / collapse to favicon rail | ⌥⌘S |
| Clear tab search and return focus to the selected tab | Escape |
| Move between pinned tiles / tab rows | Arrow keys |
| Activate a focused tab | Return or Space |
| Enter the selected tab from the sidebar toggle | Down Arrow |
| Close the selected tab, including a pin | ⌘W |
| Select tabs in pinned-first visual order | ⌘1…8; ⌘9 selects the last tab |

Tab search matches title or hostname locally and keeps private results in their
own section. It does not use ⌘F, which continues to find text in the page.
The context menu provides Pin/Unpin and Move Up/Down as alternatives to dragging.
Tab/Shift-Tab reach the profile picker, search, tab controls, New Tab and footer.
