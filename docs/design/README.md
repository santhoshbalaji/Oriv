# Oriv Mac design v3 reference mocks

Targets for the Mac Liquid Glass redesign. Overall UI follows the Neon mocks; the start page
(regular and private) follows the Fable mocks. Each mock ships as a JPEG render and the HTML
source it was rendered from; read exact sizes and colours from the HTML.

| File | Target |
| --- | --- |
| `mocks/neon-01-main-window-light.*` | Window frame, sidebar, toolbar (light) |
| `mocks/neon-02-main-window-dark.*` | Same, dark, scrolled page under the toolbar, loading progress |
| `mocks/neon-03-address-bar-focused.*` | Address focus and suggestion dropdown |
| `mocks/neon-05-private-mode.*` | Private window chrome and external-private banner (not its start-page card) |
| `mocks/fable-04-start-page.*` | Regular start page content (not its sidebar) |
| `mocks/fable-05-private-window.*` | Private start page content (not its sidebar) |
