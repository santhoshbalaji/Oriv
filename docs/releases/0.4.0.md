# Oriv 0.4.0 — contextual workspace

Built on 25 October 2026 with Xcode 27 / macOS 27.0.1. Version 0.4.0, build 4. Minimum macOS 26. Universal Apple silicon + Intel executable. The iPhone shared package targets iOS 26; there is no iPhone app target yet.

## Included

- Save the current normal page with a preview, readable text / selected passage / link-only choice and a purpose note. Capture is local and excludes form fields, editable regions and hidden content.
- Dedicated native Workspace window with content search, Today / Upcoming / Waiting, Archive and recoverable Trash.
- Immutable source snapshots, notes with revision history, actions with completion/reopening, independent due dates and reminders, and an activity timeline.
- Native local notifications with explicit permission, quick time choices, stable identifiers, cancellation and item routing on notification click.
- Native Liquid Glass controls and system navigation, readable content surfaces, system fonts and semantic colors.
- One-time bookmark migration preserving original IDs/dates. Existing browser sessions and website data are retained.
- Apple Passwords app handoff from Library and Settings. **In-page Apple Passwords AutoFill is not implemented.** See [credential integration limits](../workspace.md#apple-passwords).

## Distribution and limits

DMG: `build/releases/Oriv-0.4.0-macOS.dmg`. The companion `.sha256` file records its checksum. The installed app is `/Applications/Oriv.app`; 0.3.0 backups remain under `build/installed-backups/`.

Final DMG SHA-256: `26f3637e880ea937cd0b8f36a4846af03c7dd840eb80d46bae74a116a8ca6819`. The installed executable was compared byte-for-byte with the app mounted from this DMG; strict code-signature validation passed after installation.

This personal build is ad-hoc signed with hardened runtime. It is **not Developer ID signed or notarized** and is not an App Store release. Intel hardware, physical iPhone behavior, complete VoiceOver/Full Keyboard Access, Increase Contrast and Reduce Transparency audits remain unverified. Apple HIG guidance informed the implementation; no Apple certification is claimed.

CloudKit sync, Sign in with Apple, Apple Calendar/Reminders records, AI agents and in-page credential filling are not active. Oriv reminders use macOS notifications; they are not Apple Reminders app entries. Read [Workspace usage, privacy and architecture](../workspace.md) for capture and scheduling limits. The prior fullscreen/media acceptance evidence remains in [0.3.0](0.3.0.md); this release does not claim a new full media acceptance run.

Raw QA captures and build logs referenced here are retained locally and excluded from the public repository. Published synthetic-content screenshots are in `docs/images/`.
