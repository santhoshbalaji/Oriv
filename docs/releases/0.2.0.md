# Oriv 0.2.0 (build 2)

Verified on 25 October 2026 on the development Mac, running macOS 27.0.1 with Xcode 27.0. This is an optimized personal Release package, not a notarized public distribution.

## Changes

- YouTube live chat now receives Safari-compatible browser identification from the system WKWebView. The engine, platform identity and codec capabilities remain those of installed WebKit.
- A frame-based AppKit container separates SwiftUI layout from WebKit's fullscreen reparenting. Video and chat fill their intended fullscreen regions, and the view returns to the browser on exit.
- The app is named Oriv. Its ivory woven mark on plum takes a subtle cue from Tamil Nadu kolam. The shipping artwork is editable vector geometry in a native Icon Composer document, with default, dark and tinted settings. See [identity assets and concept prompt](../../Assets/Brand/README.md).
- The original bundle identifier and session location are retained.

## Verification

- Eight BrowserCore tests passed (`build/oriv-core-tests.log`).
- Thirteen integration tests ran: ten passed, three skipped, zero failures (`build/OrivRegressionTests.xcresult`). The skips were the container fullscreen, HEVC rendering and muted video/tab preservation checks because WebKit reported the automated window as occluded. They are not counted as passes.
- The new identity regression passed for HTTP requests and both main-frame and subframe JavaScript.
- Universal Release compilation passed (`build/oriv-release-package.log`). Both shared modules also compiled for the arm64 iPhone simulator targeting iOS 26 (`build/oriv-ios-compile.log`). There is no iPhone app UI yet.
- The installed release loaded YouTube live chat without the older-browser warning and rendered the live stream. Fullscreen entry was repeated; video with chat and video alone filled the expected regions. Escape restored the browser layout. Chat and playback (`../qa/oriv-release/youtube-chat-installed.png`, local QA artifact), fullscreen with chat (`../qa/oriv-release/youtube-fullscreen-installed.png`, local QA artifact), video-only fullscreen (`../qa/oriv-release/youtube-fullscreen-video-only.png`, local QA artifact).
- A native download Save dialog produced the expected fixture file (`../qa/oriv-release/oriv-release-download.txt`, local QA artifact).
- Existing Apple and NammaTN tabs restored after installation.

The interactive fullscreen checks used a native fullscreen Space. Automation repeatedly caused normal-window occlusion and black video capture; toggling into the visible Space restored rendered frames. Normal-window foreground fullscreen needs a further user-driven check. No visibility override or private WebKit API was introduced.

Follow-up: the normal-window check was completed in [Oriv 0.3.0](0.3.0.md), including repeated YouTube fullscreen entry/exit with rendered video and working live chat. The paragraph above records the verification boundary at the time of 0.2.0.

## Limits

The package is suitable for personal evaluation on this Mac. Apple has not certified the design or app. Default, dark and tinted icon renditions were rendered through Icon Composer, and the installed sidebar icon was inspected. Full accessibility auditing, minimum-OS hardware testing, Intel playback, authenticated providers and physical iPhone testing remain outstanding.

Mac Picture in Picture previously returned `NotSupportedError`; AirPlay receivers and commercial DRM services remain unverified. AI agents, Spaces, ad blocking, sync and the iPhone interface remain future work. See the [media audit](../media-compatibility.md) for the full compatibility scope.

Raw QA captures and build logs referenced here are retained locally and excluded from the public repository. Published synthetic-content screenshots are in `docs/images/`.
