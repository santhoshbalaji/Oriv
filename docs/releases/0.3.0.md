# Oriv 0.3.0 (build 3)

Release and local verification: 25 October 2026, macOS 27.0.1 / Xcode 27.0.

## Ad blocking

The toolbar shield offers Off, Balanced and Strict modes. Balanced is the default for normal and private tabs. Each mode uses native WebKit content rules. Exact-host exceptions are available for compatibility; regular exceptions persist locally and private exceptions clear when the last private tab closes.

Rules are ready before the first main-frame load. Popups have independent controllers, including initial blank documents, and redirects re-evaluate the destination's exception. A compilation failure stops navigation with a visible error until the user retries or chooses Off. Existing tabs are not automatically reloaded, preserving form drafts; the popover provides Reload page.

The bundled filters are an original, bounded set of common advertising/tracking domains and Strict cosmetic selectors. They update with Oriv releases. This is not a complete EasyList implementation and does not guarantee removal of YouTube or server-inserted video ads. [Detailed design, sources and limits](../ad-blocking.md).

## Normal-window fullscreen

The installed release completed two fullscreen entry/exit cycles from a normal window with the playing-video/chat fixture and Balanced filtering enabled. The player matched the fullscreen viewport; Escape restored the original 1025 × 768 viewport and 781.59375 × 400 player region both times. The page remained visible. The 0.2.0 AppKit host fix did not require further production changes for these checks.

YouTube was also verified in the installed 0.3.0 release with Balanced filtering: the live stream rendered, live chat loaded without the older-browser warning, and two player-fullscreen entry/exit cycles passed. The first started from a filled normal window; the second started after restoring the original window size. Both returned to the normal browser with Escape. Video and chat occupied their expected fullscreen regions.

Earlier attempts were obstructed by window occlusion, including with filtering Off. Once the user minimized Codex and kept Oriv visible, playback and fullscreen worked without a production code change or visibility override.

## Tests and installation

- Eight core tests passed (`build/oriv-030-core-tests.log`).

- Ad-blocking checks cover actual resource requests in normal and private contexts, all modes, first load, exception isolation, redirects, popup independence, private cleanup, bundled rule compilation, cosmetics and compilation failure recovery.
- Installed UI checks confirmed Strict cosmetics, private-site exceptions and their removal after the last private tab closed. Private-tab screenshot (`../qa/oriv-0.3.0/private-protection.png`, local QA artifact). Strict signature verification passed, and the running process was confirmed at that installed path.
